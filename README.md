# MSM

> A modern, elegant mobile application designed to help you build, track, and maintain daily habits and streaks effortlessly.

---

## 📥 Download

Pre-compiled binaries for Android and iOS are available on the [Releases](../../releases) page.

* **Android:** Download the latest `.apk` file and install it directly on your device.
* **iOS:** Download the latest `.ipa` file and sideload it using your preferred tool (e.g., AltStore, Sideloadly, or TrollStore).

---

## ✨ Features

* **Streak Tracking:** Keep track of your daily habits with an intuitive, distraction-free interface.
* **Milestone Achievements:** Unlock special color tiers and rewards as your streaks grow longer.
* **Data Persistence:** Your progress is stored securely on-device using reliable local storage.
* **Haptic Feedback:** Enjoy responsive tactile feedback tailored for every interaction.
* **Modern Navigation:** Built with Expo Router for a smooth and fluid mobile experience.
